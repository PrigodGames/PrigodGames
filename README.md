# Prigod Games

[![Prigod Games website](public/hero-castle.jpg)](https://prigodgames.github.io/PrigodGames/)

Prigod Games is a small game studio. **Prigod Idle** and **Prigod X** are both currently in active development.

## [Visit the website →](https://prigodgames.github.io/PrigodGames/)

- **Prigod Idle** is a fantasy idle autobattler for mobile and desktop, built around card runs, automated combat, and offline progression—with zero microtransactions.
- **Prigod X** is an asymmetric multiplayer action game for PC. Five heroes enter a shifting dungeon while one player controls the Overlord.

Steam pages with playable demos, plus YouTube and TikTok channels, are planned. Placeholder links are included on the website until those destinations are live.

This site is plain HTML and CSS and is hosted with GitHub Pages.
