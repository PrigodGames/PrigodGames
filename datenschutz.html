Was das Spiel speichert

Spielstand, Einstellungen und Fortschritt liegen auf dem Gerät, auf dem Sie spielen. Ich lade sie nirgendwo hoch. Wenn Sie das Spiel deinstallieren oder den Spielstand in den Einstellungen löschen, sind sie weg.

Das Spiel fragt nie nach Name, E-Mail-Adresse oder Geburtsdatum. Es greift nicht auf Kontakte, Fotos, Standort oder Dateien zu. Eine Werbe-ID wird nicht verwendet.

Bestenlisten

Es gibt Bestenlisten, eine Arena und eine Freundesliste. Nichts davon tut etwas, bis Sie unter Einstellungen → Online-Bestenlisten zustimmen und einen Anzeigenamen wählen. Vorher wird nichts verschickt.

Was übertragen wird

  • Der Anzeigename, den Sie eingeben, mit einer angehängten Nummer, damit zwei gleiche Namen unterscheidbar bleiben.
  • Eine zufällige ID, die das Spiel bei der ersten Zustimmung auf Ihrem Gerät erzeugt. Sie wird nicht aus Ihrer Hardware ausgelesen und ist keine Werbe-ID.
  • Ihre Punktzahlen sowie öffentliche Fortschrittswerte wie Level und Kampfkraft. Daraus entstehen Ranglisten und Arenapaarungen.

Ihre Freundesliste bleibt auf dem Gerät.

Wo sie liegen

Die Ranglistendaten liegen bei SilentWolf, einem gehosteten Bestenlistendienst auf Amazon Web Services. Dort kommt an, was oben steht, und sonst nichts.

Daten löschen lassen

Schreiben Sie an prigodgames@gmail.com mit dem Betreff „Löschung meiner Daten“ und nennen Sie den Anzeigenamen, unter dem Sie spielen, samt der Nummer, die im Spiel daneben steht, also zum Beispiel Hero#01234. Der Name ist das Einzige, was den Eintrag identifiziert, er muss also genau stimmen.

Ich antworte innerhalb von 30 Tagen. Das kostet nichts, und anmelden muss man sich nirgends.

Das meiste können Sie selbst erledigen. Einstellungen → Online-Bestenlisten ausschalten beendet den Versand. Wer den Spielstand in den Einstellungen löscht, wird auch die lokalen Daten samt Freundesliste und zufälliger ID los.
