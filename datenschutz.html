Im Spiel: was auf dem Gerät bleibt

Spielstand, Einstellungen und Fortschritt werden lokal auf dem Gerät gespeichert, auf dem Sie spielen. Sie werden nicht hochgeladen. Wer das Spiel deinstalliert oder den Spielstand in den Einstellungen löscht, löscht auch diese Daten.

Das Spiel fragt weder Name noch E-Mail-Adresse noch Geburtsdatum ab. Es liest keine Kontakte, Fotos, Standortdaten oder Dateien. Werbe-IDs werden nicht verwendet.

Online-Bestenlisten (freiwillig, standardmäßig aus)

Das Spiel enthält Bestenlisten, eine Arena und eine Freundesliste. All das bleibt inaktiv, bis Sie unter Einstellungen → Online-Bestenlisten zustimmen und einen Anzeigenamen wählen. Vorher wird nichts übertragen.

Was nach der Zustimmung übertragen wird

  • Der von Ihnen eingegebene Anzeigename samt einer kurzen Ziffernkennung, damit gleiche Namen unterscheidbar bleiben.
  • Eine zufällige ID, die das Spiel bei der ersten Zustimmung auf dem Gerät erzeugt. Sie wird nicht aus Geräte- oder Hardwaremerkmalen abgeleitet, ist an kein Konto gebunden und ist keine Werbe-ID.
  • Ihre Punktzahlen und ein Auszug öffentlicher Fortschrittswerte, etwa Level und Kampfkraft, damit Ranglisten und Arenapaarungen gebildet werden können.

Die Freundesliste wird ausschließlich lokal gespeichert und nicht übertragen.

Auftragsverarbeiter

Die Bestenlistendaten speichert SilentWolf, ein gehosteter Bestenlistendienst auf Amazon Web Services. Übermittelt werden nur die oben genannten Daten.

Feedback-Umfrage (freiwillig)

Im Spiel gibt es eine Feedback-Schaltfläche. Sie öffnet ein Google-Formular im Browser. Damit Sie weniger tippen müssen, enthält der Link einen kurzen technischen Auszug: Build-Typ, Versionsnummer, aktuelles Level, Anzahl der Prestige-Durchläufe, höchstes erreichtes Level, Kampfkraft, genutzte Funktionen, Spielzeit und Plattform.

Abgeschickt wird nichts, bis Sie auf dieser Seite selbst absenden. Das Formular fragt weder Namen noch E-Mail-Adresse ab. Auftragsverarbeiter des Formulars ist Google; ab dem Aufruf der Seite gelten die Datenschutzbestimmungen von Google.

Diese Website

Die Website wird über GitHub Pages ausgeliefert. GitHub speichert dabei übliche Server-Logdaten einschließlich IP-Adressen, um die Seiten auszuliefern und Missbrauch abzuwehren. Diese Verarbeitung erfolgt durch GitHub auf Grundlage berechtigter Interessen, Art. 6 Abs. 1 lit. f DSGVO.

Die Website setzt keine Cookies, nutzt keine Analyse-Werkzeuge und bindet nichts von Dritten ein. Videos und Bilder liegen auf der Seite selbst. Verweise auf YouTube, TikTok, Steam oder GitHub sind einfache Links: Vor dem Klick wird von dort nichts geladen.

Daten löschen lassen

Um einen Bestenlisteneintrag samt gespeicherter Fortschrittswerte entfernen zu lassen, schreiben Sie an prigodgames@gmail.com mit dem Betreff „Löschung meiner Daten“ und nennen Sie den Anzeigenamen, unter dem Sie spielen, einschließlich der im Spiel angezeigten Ziffernkennung (zum Beispiel Hero#01234). Dieser Name ist das einzige Merkmal des Eintrags und muss deshalb genau stimmen.

Die Bearbeitung erfolgt innerhalb von 30 Tagen. Es entstehen keine Kosten, und es ist keine Anmeldung nötig.

Vieles geht auch ohne uns: Einstellungen → Online-Bestenlisten ausschalten beendet alle Übertragungen, und das Löschen des Spielstands in den Einstellungen entfernt die lokalen Daten samt Freundesliste und zufälliger ID.
